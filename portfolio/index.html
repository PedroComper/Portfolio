Projetos

API de agendamentos para barbearia

API REST para uma barbearia cadastrar serviços e clientes e marcar horários. O sistema não deixa marcar dois atendimentos no mesmo horário, exige e-mail único por cliente e, quando um agendamento é cancelado, ele fica registrado no histórico em vez de ser apagado.

Organizei o código em controller, service e repository, com DTOs separando o que entra e o que sai da API. Os erros passam por um handler global que devolve sempre o mesmo formato de JSON. As regras principais têm testes unitários com JUnit e Mockito, o banco é versionado com Flyway e a documentação é gerada pelo Swagger.

Java 25, Spring Boot 4, Spring Data JPA, SQL Server, Flyway, JUnit, Mockito, Swagger
